ในวีคนี้ผมได้ทำของที่อาจารย์ส่งมาให้ซึ่งมาพร้อมกับเฉลยทำให้ผมได้ดูวิธีการเขียนที่ถูกต้องเปรียบเทียบกับของที่ตัวเองได้ทำทำให้เข้าใจอะไรเยอะขึ้นแล้วรอบนี้ได้ฝึกเรื่องของ Local Storage ก็รู้สึกได้เข้าใจมากขึ้นครับ
เรื่องที่ได้วันนี้ฃ
- Local Storage เก็บข้อมูลแบบ String เท่านั้น
- ต้องใช้ JSON.stringify() ก่อนเก็บข้อมูลที่เป็น Object หรือ Array
- ใช้ JSON.parse() เพื่อแปลงข้อมูลกลับก่อนใช้งาน
- ตรวจสอบค่าที่ดึงจาก Local Storage ว่าไม่ใช่ null ก่อน parse
