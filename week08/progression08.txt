ในวัคผมได้ลองทำแบบฝึกหัดอาจารย์บอกเลยครับว่า โครตยาก แต่ได้อะไรเยอะมากครับใช้เวลาทำอยู่ 4 ชมเข้าใจการสร้าง Element และ การใช้ Eventlistner มากกขึ้นได้เข้าใจว่าลำดับการใช้งานควรเรียกยังไงให้ถูกต้องเพราะระหว่างทางผมแก้เยอะมากเพราะเวลาจะสร้าง element ผทชอบเขียนรวบไปใน append เลยได้เรียนรู้ครับว่าควรใช้ยังไงทั้งยังได้ฝึก Logic บางอย่างด้วยอยากตัวเรื่องของระบบ Random วีคทำให้รู้สึกว่ายังมีเรื่องที่ต้องฝึกเพิ่มอยู๋ครับเลยคิดว่าวีคหน้าจะไปติวพื้นฐานมาเพิ่ม
สิ่งที่ได้ทำ
- เชื่อมโยง UI กับข้อมูล
- ใช้ getElementById() เพื่อดึง elements จาก HTML (ฟอร์ม, ปุ่ม, พื้นที่แสดงคำคม)
- สร้างระบบแสดงผลคำคม
- สร้างฟังก์ชัน createQuoteElement() เพื่อสร้าง <section> สำหรับแต่ละคำคม พร้อมปุ่ม Edit / Delete
- ใช้ renderQuotes() เพื่อรีเฟรชรายการทั้งหมดบนหน้าเว็บ
- เพิ่ม/แก้ไข/ลบคำคมผ่านฟอร์ม
- ใช้ฟอร์มเดียวกันสำหรับ เพิ่ม และ แก้ไข
- กำหนดสถานะ submittype เพื่อสลับระหว่างโหมด add/edit
- แก้ไขเนื้อหา quote โดยกรอกข้อมูลเดิมเข้า input เมื่อกด Edit
- แสดงคำคมแบบสุ่ม
- ใช้ปุ่ม Random เพื่อสุ่มแสดง quote แบบสวยงาม
- แสดงข้อความ "content" — author ในส่วนที่กำหนด
- เชื่อมต่อกับ logic จาก quote.js
- ใช้ฟังก์ชัน addQuote, updateQuote, deleteQuote, getAllQuotes จาก quote.js เพื่อจัดการข้อมูล quote
- ใส่ event listener ให้ทุกปุ่ม
- ปุ่มในแต่ละ quote (Edit / Delete)
- ปุ่ม Random
- ฟอร์ม submit
